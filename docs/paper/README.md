# Manuscript draft

`nanoCAS_BMC_Bioinformatics_draft.docx` is the working draft of the BMC Bioinformatics Software article.
Word comments mark every passage that needs case-study data or an author decision.

`paper.js` regenerates the document (`npm install docx` then `node paper.js` in this directory);
`fig1_architecture.png` and `fig2_interface.png` are the embedded figures.
