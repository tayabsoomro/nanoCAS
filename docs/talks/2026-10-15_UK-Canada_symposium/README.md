# nanoCAS talk, Joint UK–Canada Symposium, 15 October 2026

`nanoCAS_UK-Canada_Symposium_2026-10-15.pptx` is the 15-slide deck for the 2:05–2:20 pm slot in Session 3.
Speaker notes are on every slide. `build.js` regenerates it (`npm install pptxgenjs react-icons react react-dom sharp`,
then `node build.js`); `assets/` holds the AAFC banner and footer artwork, the screenshots and the GitHub QR code.
